# Analysis

This folder holds lightweight analysis helpers for study outputs.

Current script:

- `summarize_results.py` - loads `data/raw/study_results.csv` and prints
  grouped descriptive statistics

The MVP analysis intentionally stays simple:

- descriptive summaries by condition
- mean pre-test and post-test scores
- mean gain
- timed accuracy and duration

If the project grows, this folder can later add notebooks, plots, and more
formal statistics.
