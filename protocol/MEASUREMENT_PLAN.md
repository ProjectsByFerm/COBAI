# COBAI Measurement Plan

## Primary Outcomes

- post-test score
- timed-task accuracy
- timed-task completion time

These should be reported together so speed is not rewarded without correctness.

## Secondary Outcomes

- pre/post learning gain
- confidence rating
- usefulness rating
- LLM metadata such as model and prompt version

## Minimum Export Fields

- participant ID
- condition
- module ID
- content version
- prompt version
- model
- pre-test score
- post-test score
- timed-task accuracy
- timed-task duration
- participant background fields
- notes

## Analysis Style

For the MVP, keep the analysis lightweight:

- descriptive statistics by condition
- average pre/post/gain values
- average timed accuracy and duration

If the final dataset is small, avoid overclaiming significance.
